boilerplate for Program.cs:
```cs
using System;  
  
namespace Sandbox {  
  class Program  
  {  
    static void Main(string[] args)  
    {  
      Console.WriteLine("Hello World!");  
    }  
  }  
}
```


How to create a console application using a template in C# (using dotnet cli)
`dotnet new <template> -n <app-name>`
  
To list the templates, you run:  
`dotnet new list`
